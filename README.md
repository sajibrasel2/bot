# SweetNikita Group Manager Bot & Admin Panel Setup Guide

এই প্রজেক্টটি একটি শক্তিশালী **টেলিগ্রাম গ্রুপ ম্যানেজার বট** এবং এর ব্যাকএন্ড সেটিংস কন্ট্রোল করার জন্য তৈরি **Flask ওয়েব অ্যাডমিন প্যানেল**। একই সাথে এতে রয়েছে ট্রাফিক মনিটাইজেশনের জন্য একটি ইন্টারেক্টিভ ল্যান্ডিং পেজ (Adult Zone Live)।

অন্য কেউ যদি এই বটটি নিজের গ্রুপ বা চ্যানেলের জন্য ব্যবহার করতে চায়, তবে নিচে দেওয়া ধাপগুলো অনুসরণ করে খুব সহজেই এটি সেটআপ ও চালু করতে পারবে।

---

## ১. প্রয়োজনীয় সফটওয়্যার (Prerequisites)
বটটি চালু করার আগে ডিভাইসে (PC বা VPS) নিচের সফটওয়্যারগুলো থাকতে হবে:
1. **Python 3.8 বা তার বেশি**: [Python অফিসিয়াল সাইট](https://www.python.org/) থেকে ডাউনলোড করে নিন। (Install করার সময় অবশ্যই **"Add Python to PATH"** চেক বক্সে টিক দিবেন)।
2. **XAMPP / MySQL Database**: লোকালহোস্টে ডেটাবেজ চালানোর জন্য XAMPP ডাউনলোড করে MySQL স্টার্ট করে রাখুন।
3. **Telegram Bot Token**: টেলিগ্রামে [@BotFather](https://t.me/BotFather) এ গিয়ে `/newbot` লিখে নতুন বট তৈরি করে টোকেন (Token) সংগ্রহ করুন।

## ২. ইনস্টলেশন ও সেটআপ (Step-by-Step Setup)

### ধাপ ১: প্রজেক্ট ডাউনলোড ও লাইব্রেরি ইনস্টল
প্রজেক্ট ফোল্ডারে টার্মিনাল/কমান্ড প্রম্পট (CMD) ওপেন করুন এবং প্রয়োজনীয় সব পাইথন প্যাকেজ ইনস্টল করতে নিচের কমান্ডটি রান করুন:
```bash
pip install -r requirements.txt
```

### ধাপ ২: ডেটাবেজ তৈরি করা (Database Setup)
1. XAMPP Control Panel ওপেন করে **Apache** এবং **MySQL** চালু (Start) করুন।
2. ব্রাউজারে `http://localhost/phpmyadmin` এ যান।
3. **New** এ ক্লিক করে একটি নতুন ডেটাবেজ তৈরি করুন। ডেটাবেজের নাম দিন: `sweetnikita_bot` (বা আপনার সুবিধাজনক যেকোনো নাম)।

### ধাপ ৩: কনফিগারেশন সেটআপ (`.env` ফাইল)
প্রজেক্টের রুট ফোল্ডারে থাকা `.env` ফাইলটি নোটপ্যাড বা যেকোনো কোড এডিটর দিয়ে ওপেন করুন এবং আপনার তথ্য দিয়ে নিচের ক্ষেত্রগুলো পূরণ করুন:
```env
# Bot Credentials
BOT_TOKEN=আপনার_টেলিগ্রাম_বট_টোকেন
BOT_USERNAME=আপনার_বটের_ইউজারনেম
OWNER_ID=আপনার_টেলিগ্রাম_ইউজার_আইডি  # বটের প্রধান মালিকের আইডি
LOG_CHANNEL_ID=0

# MySQL Configuration
MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_USER=root
MYSQL_PASSWORD=
MYSQL_DB=sweetnikita_bot

# Web Admin Panel Login Config
PANEL_USER=admin
PANEL_PASSWORD=nikita2024    # অ্যাডমিন প্যানেলে লগইন করার পাসওয়ার্ড
FLASK_SECRET_KEY=যেকোনো_সিক্রেট_কী

# Hosted Web App URL (ল্যান্ডিং পেজের লিংক)
WEB_APP_URL=https://আপনার-ডোমেইন.com/
```

## ৩. প্রজেক্ট চালু করা (Running the Project)

লোকালহোস্ট বা সার্ভারে বট এবং ওয়েব প্যানেল দুটি আলাদা প্রসেসে রান করতে হবে।

### ১. টেলিগ্রাম বট চালু করুন:
টার্মিনালে নিচের কমান্ডটি রান করুন:
```bash
python main.py
```
*বটটি চালু হয়ে ডেটাবেজে প্রয়োজনীয় টেবিলগুলো (warns, chat_settings, notes, users, bot_admins) স্বয়ংক্রিয়ভাবে তৈরি করে নিবে।*

### ২. ওয়েব অ্যাডমিন প্যানেল চালু করুন:
নতুন আরেকটি টার্মিনাল উইন্ডো ওপেন করে রান করুন:
```bash
python web/app.py
```
*এখন যেকোনো ব্রাউজারে `http://localhost:5000` লিংকে গিয়ে আপনার `.env` ফাইলে দেওয়া `PANEL_USER` এবং `PANEL_PASSWORD` দিয়ে লগইন করে গ্রুপের সেটিংস ও বট অ্যাডমিন কন্ট্রোল করতে পারবেন।*

## ৪. গ্রুপে বটের ব্যবহার (Bot Usage Guide)

1. **গ্রুপে বট যোগ করুন**: প্রথমে আপনার টেলিগ্রাম গ্রুপে বটটিকে যুক্ত (Add) করুন এবং তাকে **Administrator** হিসেবে প্রমোট করুন। বটকে অবশ্যই "Delete Messages" এবং "Ban Users" পারমিশন দিতে হবে।
2. **ইনলাইন মডারেশন প্যানেল**: গ্রুপে বটের কমান্ড টাইপ না করে সহজেই মেম্বারদের কন্ট্রোল করতে:
   - যেকোনো মেম্বারের পাঠানো মেসেজে **Reply** করুন।
   - টাইপ করুন `/panel` বা `/control` লিখে সেন্ড করুন।
   - সাথে সাথে বটের পক্ষ থেকে একটি ইনলাইন বাটন কন্ট্রোল প্যানেল আসবে। সেখান থেকে এক ক্লিকে মেম্বারকে **Warn, Ban, Mute, Kick** করতে পারবেন বা মেসেজ **Pin/Delete** করতে পারবেন।
3. **টেলিগ্রাম Web App**: ব্যবহারকারীরা যখন বটের প্রাইভেট চ্যাটে এসে `/start` দিবে, তখন তারা **"💋 লাইভ চ্যাট শুরু করুন (Web App)"** বাটনটি দেখতে পাবে। এটিতে ক্লিক করলে ল্যান্ডিং পেজটি সরাসরি টেলিগ্রামের ভেতর মোবাইল ফ্রেন্ডলি ফুল-স্ক্রিন উইন্ডো হিসেবে ওপেন হবে।
